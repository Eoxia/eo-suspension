# eo-suspension
Interface pour suspendre un site internet

**Utilisation**
- Télécharger le fichier eo-suspension.php
- Modifier la clé unique
- Uploader le fichier à la racine du site internet (où se trouve le .htaccess)
- Ecrire dans l'url : https://monsiteinternet.com/eo-suspension.php?key=VOTRE_CLE
- Suspendre ou annuler la suspension du site
